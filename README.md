# NMCHV Student

Персональный кабинет образовательного развития (ученик / тьютор / администратор).
Стек: Node.js ≥ 22.5 (без зависимостей), встроенный SQLite, ванильный ES-модульный фронтенд, дизайн-токены NMCHV.

## Запуск
    npm start            # http://localhost:3000
    npm run reset-db     # удалить БД (демо-данные создадутся заново)

Демо-аккаунты (пароль `Demo-2026!`): alexey@demo.nmchv.local (ученик), tutor@demo.nmchv.local, admin@demo.nmchv.local.

## Боевой режим
    SEED_DEMO=0 ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='...' COOKIE_SECURE=1 PORT=3000 npm start
Переменные: DB_PATH, APP_TZ, SHOW_DEMO_LOGINS=0 (скрыть демо-входы), DEMO_PASSWORD.
Запускать за HTTPS-прокси (nginx/caddy). Данные — в `data/nmchv-student.db`, резервная копия = копия файла.

## Безопасность
Пароли — scrypt; сессии — случайный токен в HttpOnly-cookie (в БД хранится только хэш); права проверяются на сервере в каждом запросе
(ученик видит только себя, тьютор — только связанных учеников, админ — всех); CSRF-заголовок на изменяющих запросах; валидация всех полей; CSP.
